# PokéAPI SDK

An open-source TypeScript SDK for [PokéAPI](https://pokeapi.co), generated with the [Voxgig SDK generator](https://voxgig.com/sdk) from an OpenAPI specification.

## Project structure

- `api.yml` — OpenAPI specification for PokéAPI.
- `myapi-sdk/ts/` — **the generated TypeScript SDK** (source in `src/`, compiled output in `dist/`, tests in `test/`).
- `myapi-sdk/.sdk/` — Voxgig generator configuration, model, templates and build scripts.
- `myapi-sdk/examples/live-check.js` — smoke test against the live PokéAPI.
- `REPORT.md` — developer-experience report on the Voxgig generator.
- `LICENSE` — MIT License.

## Using the SDK

```bash
cd myapi-sdk/ts
npm install
npm run build
```

```js
const { MyapiSDK } = require('./dist/MyapiSDK')

const client = new MyapiSDK({})
const pikachu = await client.Pokemon().load({ id: 'pikachu' })
console.log(pikachu.data())
```

PokéAPI is public and needs no API key. The generated [`myapi-sdk/ts/README.md`](myapi-sdk/ts/README.md) and [`REFERENCE.md`](myapi-sdk/ts/REFERENCE.md) document every entity.

## Testing

Offline tests (generated by the SDK generator):

```bash
cd myapi-sdk/ts
npm test
```

Live check against the real API (needs internet access):

```bash
cd myapi-sdk/ts && npm run build && cd ..
node examples/live-check.js
```

## Regenerating the SDK

```bash
cd myapi-sdk/.sdk
npm install
npm run add-target ts   # only needed once; registers the TypeScript target
npm run build
npm run generate
```

A language target must be added before `npm run generate` produces any SDK code. Generation overwrites `myapi-sdk/ts/`, so change the model or templates in `myapi-sdk/.sdk/` rather than editing generated files.
